# Failure / Edge-Case Matrix

Principle: degrade loudly, never silently; "couldn't check" is never
converted into "clean".

| # | Condition | Detection | Behavior | Escalation surface |
|---|---|---|---|---|
| F1 | Tier-2 exceeds 180 s cap | `WaitForExit(180000)` returns false | `Kill($true)` (whole tree incl. node/MCP children); stderr + partial stdout salvaged to `escalations/`. D9 (2026-08-28): a COMPLETE valid verdict in the salvage is accepted as a normal run; a partially valid one applies per validated connection, the rest go to Tier-3 (`tier2_timeout`); unparsable salvage = IMMEDIATE Tier-3 on all keys | Tier 3 + urgent toast (unless fully salvaged) |
| F2 | Tier-2 nonzero exit / unparseable or schema-invalid verdict / verdict omits packet keys | stdout parse + schema check | one retry in the same cycle; second failure -> Tier 3, reason `tier2_failed` | Tier 3 + urgent toast |
| F3 | claude CLI missing / auth expired / launch throws | Process start exception or instant exit | No Tier-2 possible: urgent toast "netwatch: tier2 unavailable" + op-log ERROR; retry next cycle with backoff (10 -> 30 -> 60 min); residual queue keeps accumulating, nothing dropped | Toast (Tier 3 cannot work either — human must fix CLI) |
| F4 | Npcap/tshark absent, capture start fails, or tshark dies repeatedly | child exit code / stderr; restart counter | Restart with backoff (5 s, 30 s, 300 s); after `max_restarts_before_degraded` (5) enter DEGRADED-SNI: continue ETW-only, one toast, `collector_health.sni_capture = "degraded"/"unavailable"` in every packet so Tier 2 weighs missing SNI attribution correctly | One-time toast + packet flag |
| F5 | ETW DNS-Client channel disabled/not readable | startup probe (`Get-WinEvent -MaxEvents 1` on channel) + runtime errors | Continue SNI-only; `collector_health.dns_etw = "unavailable"`; toast once at startup with the `wevtutil` enable hint (`install/enable-etw.ps1` is the implementer's one-time fix) | One-time toast + packet flag |
| F6 | Both attribution sources down | F4 + F5 both active | Collector keeps sampling; ALL non-CIDR-whitelisted traffic becomes residual -> would flood Tier 2. Flood guard: if residual set > 3x batch cap in one cycle AND both sources down, do NOT invoke Tier 2; urgent toast "netwatch blind — attribution lost" | Urgent toast (human decision) |
| F7 | Own-IP detection fails (resolver down, no internet) | `Resolve-DnsName` error | Keep last-known + recorded static (`203.0.113.10`) as exclusion set; never operate with an empty exclusion set; op-log WARN | none (fail-closed) |
| F8 | Own IP changed (DHCP/ISP) | hourly re-detect differs | Update `state/ownip.json` (detected + last-known kept); old value stays excluded for 7 days (grace against flapping) | op-log INFO |
| F9 | IP churn on whitelisted domains (CDN edges) | — | Non-event by design: matching is domain-based; new edge IP under same SNI/DNS name matches the same entry | none |
| F10 | Residual IP with NO domain attribution for a whitelisted process (e.g. Anthropic edge before SNI seen) | classify | Stays residual -> normal debounce -> Tier 2 with `attribution.source="none"` + ASN context; suppression prevents repeat churn | Tier 2 |
| F11 | Reputation quota exhausted (VT 4/min / daily budget) | `state/repquota.json` ledger | Tool returns `quota_exhausted`; prompt rule: not evidence, continue other checks; Tier 1 never spends quota (Tier-2-only lookups, per GOAL) | none |
| F12 | Reputation API unreachable / key invalid | HTTP error in tool | Tool returns `{error:"lookup_unavailable"}`; same rule as F11 — never blocks, never counts as clean evidence | none |
| F13 | Process exits before Tier 2 runs (short-lived beacon) | dead PID | Packet carries recorded `image_path`, `command_line`, state history; `check_process_lineage` returns `alive:false`; signature/hash checks still run on the image file; missing image file (F14) escalates immediately | Tier 2 |
| F14 | Residual process image deleted from disk | `image_exists=false` at sample time | IMMEDIATE Tier-2 trigger (bypasses 10-min spacing) — classic drop-run-delete pattern; if also short-lived, packet still has recorded metadata | Tier 2 (fast path) |
| F15 | Unclassified INBOUND connection | direction=inbound, no whitelist match | IMMEDIATE Tier-2 trigger (bypasses spacing) | Tier 2 (fast path) |
| F16 | Toast fails (BurntToast missing/broken) | try/catch in toast.psm1 | op-log ERROR; pipeline continues — ALARM surface is the Tier-3 window, not the toast; CLEAN outcomes lose their notification only | op-log |
| F17 | System sleep/resume | tick gap > 3x interval | Treat next sample as fresh baseline for seen-counters; ETW bookmark catches up missed DNS events; no false "new connection" flood (keys are stable) | op-log INFO |
| F18 | Second Tier-1 instance started | named mutex `Global\netwatch-tier1` held | New instance exits 0 immediately with op-log line | none |
| F19 | ALARM while previous alarm still open | `alarms/<id>-open.marker` present | New alarm file written + toast; NO second Tier-3 window for the same keys; keys of open alarm suspended from re-escalation while the marker exists. Marker deletion = operator resolution: keys evicted from the queue + suppressed for the standard TTL (cooldown, 2026-08-27 repeat-alarm fix) | Toast + alarm file |
| F20 | Whitelist file corrupt / schema-invalid at load | JSON parse/schema check at startup + on change | On HOT-RELOAD: keep last-good in-memory copy, one toast per bad-load episode + op-log ERROR. At STARTUP a fresh process has no last-good copy, so a corrupt file fail-fasts the start (scheduled-task auto-restart surfaces it) — running with an empty whitelist would flood Tier 2 | Toast (reload) / failed start (startup) |
| F21 | State root unwritable / disk full | write failures | op-log to stderr fallback; monitoring continues in-memory. No toast by design (2026-08-28 review): a toast during an I/O failure is itself unreliable and spawns a child per attempt | stderr fallback |
| F22 | tshark sees TLS/HTTP on non-configured port | capture filter misses it | Known limitation: SNI only for `capture_ports` (default 443, 8443) and Host headers only for `sni.http_ports` (default 80, added 2026-08-28); other ports fall back to DNS attribution or arrive unattributed -> residual -> Tier 2. Config-extendable | Tier 2 (as residual) |
| F23 | Hostile text in process cmdline/domain (prompt injection at Tier 2) | — | Contained by design: no destructive tools exist; own-IP guard not model-overridable; worst-case CLEAN = 24 h suppression of one key + human-reviewed proposal; worst-case ALARM = summons human (fail-safe); prompt rule 1 flags instruction-like data as suspicious | design property |
| F24 | Tier-2 answers CLEAN but omits/renames keys | parser cross-checks packet keys vs verdict keys | Treated as F2 (invalid verdict) — retry then Tier 3. Prevents an injected "partial verdict" from silently dropping a connection | Tier 3 |
